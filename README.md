# The Bayesian Brain Hypothesis — Code

This repository accompanies the course **The Bayesian Brain Hypothesis**, taught at ENS.

Notebooks illustrating the material covered in some of the classes are (or will be) made available here. Each notebook is self-contained and can be run independently.

## Notebooks

- [`basic_2_probabilistic_population_code.ipynb`](basic_2_probabilistic_population_code.ipynb): Probabilistic population codes (Ma, Beck, Latham & Pouget, 2006), covering decoding of a stimulus from population activity and cue combination via probabilistic population codes.

More notebooks will be added as the course progresses.
